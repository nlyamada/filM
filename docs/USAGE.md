# filM の使い方 (日本語)  /  [English](USAGE.en.md)

画面右側の **キー一覧** に、いまのキー割り当てが出ます。**Shift を押している間は Shift+キーの内容に切り替わります**。
一覧の行は **クリックでも実行できます** (`F1` で表示/非表示)。キー割り当ては **設定ダイアログ (`Ctrl+,` または各バー右端の ⚙ → 設定)** で変えられます (`keymap.json` を直接編集してもかまいません)。

## 基本
- `↑` `↓` で移動、`Enter` でフォルダに入る / ファイルを開く、`Backspace` で上のフォルダへ、`Shift+Backspace` でドライブのルートへ。
- 1キー操作は **ファイル一覧にフォーカスがあるとき** に効きます。`Esc` でいつでも一覧へ戻れます。
- 一覧では IME が無効になります (1キー操作のため)。名前変更の入力欄では日本語を入力できます。

## マーク (複数選択)
`Space` でマーク (アイコンにチェック印と、行に色が付きます)。コピー・移動・削除・zip などは、**マークがあればマーク全件、無ければカーソル位置の 1 件**が対象です。

## エイリアス (フォルダの別名)
- `Shift+J` (または `Ctrl+D`) でいまのフォルダを登録 (名前・呼び出しキー・フォルダ)。左の一覧に出ます。
- フォルダ入力のダイアログ (`G` `O` `Shift+C` `Shift+M`) で **TAB を押すとフォルダ名・エイリアス名を補完**します。
  例: エイリアス `HOME` = `C:\home` のとき、`HOME\l` で TAB → `HOME\lib\`。続けて TAB で次の候補。
- エイリアス欄は名前順に並びます。呼び出しキーは **Shift を押している間だけ** 表示されます。
- 一覧にフォーカス (`J`) して: `Enter` で移動、`Shift+Enter` または **Shift+呼び出しキー** で新しいタブに開いてファイル一覧へ戻る、`F2` 編集、`Delete` 削除。Shift なしの文字キーは、その文字で始まる項目へ移動します。
- `Shift+E` で定義ファイル (`favorites.json`) をエディタで開けます。保存してこのウィンドウに戻ると反映されます。

## 元に戻す (Z)
このアプリで行った **コピー・複製・移動・リネーム・フォルダ作成・zip・解凍・ショートカット作成・ごみ箱への削除・属性変更** を、新しい順に取り消します
(最大 50 件、アプリを閉じると消えます)。**完全削除は戻せません。**

## ビューワー (プレビュー欄) (V)
`V` で、**ファイル一覧の下**にビューワーを出したり隠したりします。表示している間は一覧のカーソルに合わせて内容が変わり、画像・Markdown・テキストを見られます (見るだけで、編集はできません。バイナリは案内だけ)。境界をドラッグして高さを変えられます (保存されます)。
- **スクロール**: マウスが欄の上にあれば、一覧にフォーカスがあってもホイールでスクロールします。`Tab` で欄の中にフォーカスが移り、矢印キー・PageUp・PageDown・`Home`・`End` でもスクロールできます。欄の中で `Tab` を押すと一覧へ戻り (ビューワーは開いたまま)、**`Esc` を押すとビューワーを閉じて一覧へ戻ります**。`Shift+V` で一覧を隠して欄を広げます (もう一度で戻る)。欄の見出し右端の `✕` でも閉じます。
- **画像**: `←` `→` (PageUp・PageDown・Space・Backspace) 前後の画像 / `+` `-` またはホイール 拡大縮小 / `0` 全体表示 / `1` 等倍 / ドラッグで移動 / ダブルクリックで全体 ⇔ 等倍。スマホ写真の向き (EXIF) を反映します。JPEG・PNG・BMP・GIF・TIFF のほか、Windows にコーデックがあれば HEIC・WebP なども開けます。巨大な画像は縮小して読み込みます。
- **Markdown**: 見出し・表・コードブロック・タスクリスト・画像、`$...$` / `$$...$$` の数式 (KaTeX)、` ```mermaid ` の図に対応します。画像は `![](img/a.png)` のほか `../images/a.png` のように文書より上のフォルダにあるものも、同じドライブ内なら表示します。`F5` で再読み込み。文書内の別の `.md` へのリンクは欄の中で開き、`http(s)` のリンクは既定のブラウザで開きます。それ以外のローカルファイルはクリックしたときだけ開き、画像・テキスト・PDF・音声・動画以外は確認が出ます (プログラムやスクリプトはリンクからは開きません)。**安全のため、文書内のスクリプトは動かしません。インターネット上の画像は、既定では読み込みません** (設定で「Markdown でインターネット上の画像も表示する」をオンにすると表示します。画像の取得のたびに外部へ接続します)。**Microsoft Edge WebView2 Runtime** (Windows 11 には標準で入っています) と、exe の隣の `WebView2Loader.dll`・`viewer\` フォルダが必要です。無いときは Markdown の元の文字をそのまま表示します。
- **テキスト**: 文字コード (UTF-8 / BOM 付き UTF-8 / UTF-16 / ANSI) と改行を自動判定して、見出しに出します (10 MB まで)。`Alt+Z` で折り返しの切り替え。編集したいときは `E` で、設定で選んだテキストエディタ (Windows の既定 / メモ帳 / 任意のプログラム) が開きます。
## タブセット (仮想デスクトップのようなタブの組)
- L でメニュー (切替・名前変更・削除)、Shift+L で新しいセットを追加 (いまのフォルダ 1 枚のタブで始まります)。タブ欄右端の ⚙ からも操作できます。
- タブ・セットは変更のたびに session.json へ保存され、次回起動時に復元されます。

## 画面の調整
- 欄の境界はドラッグで動かせます。幅とウィンドウの大きさは session.json に保存されます。
- 各バー右端の ⚙: エイリアス欄=エイリアスの登録・編集・削除、タブ=タブとセットの操作、キー操作=設定・keymap.json の編集・既定値に戻す。

## 設定 (Ctrl+,)
- **言語**: 画面右下の `JA | EN` をクリックするか、設定ダイアログで切り替えます。初回は OS の言語に合わせます。
- **テーマ**: システムに合わせる / ライト / ダーク。
- **テキストエディタ**: Windows の既定 / メモ帳 / 任意のプログラム (パス指定)。`E` キーや設定ファイルの編集で使います。
- **キー割り当て**: コマンドを選んで「変更...」(割り当てたいキーを実際に押す)、「追加...」(同じコマンドに別のキーを足す)、「解除」、「既定値に戻す...」。すでに使われているキーは、置き換えるか確認します。

## 設定ファイルの場所
keymap.json / favorites.json / session.json / settings.json は **exe と同じフォルダ** に作られます (書き込めない場所に置いたときだけ %APPDATA%\filM)。旧版 (SpringM Clone) の %APPDATA%\SpringMClone の設定は初回に引き継ぎます。
「TXT ファイル」などのファイルの種類名は Windows が付けるもので、OS の言語に従います。
